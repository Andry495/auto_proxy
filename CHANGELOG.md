# 📋 Changelog

Все значимые изменения в проекте Proxy Collector будут документированы в этом файле.

## [1.0.0] - 2024-01-18

### ✨ Добавлено
- **Основная функциональность:**
  - Автоматический парсинг прокси с 4 популярных сайтов
  - Поддержка протоколов HTTP, HTTPS, SOCKS4, SOCKS5
  - Многопоточная проверка доступности прокси
  - Измерение времени отклика и скорости

- **Интерфейс:**
  - Современный Windows Forms интерфейс
  - Интерактивная таблица с сортировкой
  - Мощные фильтры по типу, стране, IP
  - Статистика в реальном времени
  - Прогресс-бары для длительных операций

- **Фоновый режим:**
  - Сворачивание в системный трей
  - Автоматические проверки каждые 5 минут
  - Непрерывная работа в фоне
  - Уведомления о статусе операций

- **Сохранение данных:**
  - Локальные файлы в форматах TXT, JSON, CSV
  - Автоматическое резервное копирование
  - Экспорт отфильтрованных данных
  - Структурированное хранение с метаданными

- **Дополнительные возможности:**
  - Автообновление каждые 30 секунд
  - Обработка ошибок и исключений
  - Логирование операций
  - Настраиваемые параметры

### 🏗️ Архитектура
- **Модели:** ProxyServer с полной информацией о прокси
- **Сервисы:** Parser, Checker, Storage для разделения логики
- **Интерфейс:** MainForm с полным функционалом
- **Конфигурация:** Гибкие настройки через App.config

### 🔧 Технические детали
- **Платформа:** .NET 8.0 Windows Forms
- **Парсинг:** HtmlAgilityPack для веб-скрапинга
- **Проверка:** HttpClient с настраиваемыми таймаутами
- **Многопоточность:** SemaphoreSlim для контроля потоков
- **Сохранение:** JSON сериализация с резервным копированием
