## 🚀 Быстрый старт

### 1. Форк и клонирование
```bash

# Затем клонируйте ваш форк

cd auto_proxy

# Добавьте оригинальный репозиторий как upstream
git remote add upstream https://github.com/Andry495/auto_proxy.git
```

### 2. Создание ветки
```bash
# Создайте ветку для вашей функции
git checkout -b feature/your-feature-name

# Или для исправления бага
git checkout -b fix/your-bug-fix
```

- Внесите необходимые изменения

git commit -m "Add: краткое описание изменения"

## 📋 Стандарты кодирования

### C# Style Guide
```csharp
// Используйте PascalCase для классов и методов
public class ProxyServer
{
    public string IpAddress { get; set; }
    
    // Используйте camelCase для локальных переменных
    public void CheckProxy()
    {
        var httpClient = new HttpClient();
        // ...
    }
}

// Используйте async/await для асинхронных операций
public async Task<List<ProxyServer>> ParseProxiesAsync()
{
    // ...
}
```

### Именование
- **Классы:** PascalCase (`ProxyServer`, `ProxyParser`)
- **Методы:** PascalCase (`ParseProxies`, `CheckAvailability`)
- **Переменные:** camelCase (`ipAddress`, `responseTime`)
- **Константы:** UPPER_CASE (`MAX_CONCURRENT_CHECKS`)

## 🧪 Тестирование

### Ручное тестирование
- Проверьте все основные функции
- Протестируйте с различными данными
- Проверьте обработку ошибок
- Убедитесь в корректности UI

### Автоматические тесты (планируется)
```csharp
[Test]
public void ParseProxy_ValidInput_ReturnsProxy()
{
    // Arrange
    var parser = new ProxyParser();
    var html = "<table><tr><td>192.168.1.1</td><td>8080</td></tr></table>";
    
    // Act
    var result = parser.ParseHtml(html);
    
    // Assert
    Assert.AreEqual("192.168.1.1", result.IpAddress);
    Assert.AreEqual(8080, result.Port);
}
```
