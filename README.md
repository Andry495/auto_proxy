# Proxy Collector

Программа для коллекционирования и управления прокси серверами с автоматической проверкой доступности и скоростных характеристик.

## Возможности

- **Автоматический парсинг прокси** с популярных сайтов:
  - hide-my-name.com/proxy-list/
  - proxyscrape.com/free-proxy-list
  - freeproxylist.ru/
  - free-proxy-list.net/

- **Поддержка различных типов прокси**:
  - HTTP
  - HTTPS
  - SOCKS4
  - SOCKS5

- **Автоматическая проверка доступности** прокси серверов
- **Измерение скорости** и времени отклика
- **Сохранение в локальные файлы** (TXT, CSV, JSON)
- **Фильтрация и сортировка** по различным параметрам
- **Фоновый режим работы** с сворачиванием в системный трей
- **Автоматическое обновление** прокси списков

## Установка и запуск

1. Убедитесь, что у вас установлен .NET 6.0 или выше
2. Откройте проект в Visual Studio или используйте командную строку:
   ```bash
   dotnet build
   dotnet run
   ```

## Использование

### Основные функции

1. **Парсинг новых прокси** - кнопка "Парсить новые"
2. **Проверка доступности** - кнопка "Проверить все"
3. **Обновление списка** - кнопка "Обновить"
4. **Экспорт данных** - кнопка "Экспорт"

### Фильтрация

- **По типу прокси**: HTTP, HTTPS, SOCKS4, SOCKS5
- **По стране**: выберите из списка доступных стран
- **По IP адресу**: введите часть IP для поиска
- **Только доступные**: показывать только рабочие прокси

### Настройки

- **Автообновление**: автоматическое обновление каждые 30 секунд
- **Фоновый режим**: работа в системном трее с периодическими проверками
- **Экспорт**: сохранение в различных форматах (TXT, CSV, JSON)

### Фоновый режим

При включении фонового режима программа:
- Сворачивается в системный трей при минимизации
- Продолжает работать в фоне
- Автоматически проверяет прокси каждые 5 минут
- Показывает уведомления о статусе

## Форматы сохранения

### Текстовый формат (proxies.txt)
```
# Proxy List - Generated: 2024-01-01 12:00:00
# Format: IP:Port|Type|Country|Speed|Available|LastChecked|Source
192.168.1.1:8080|HTTP|United States|100|True|2024-01-01 12:00:00|https://example.com
```

### JSON формат (proxies.json)
```json
[
  {
    "IpAddress": "192.168.1.1",
    "Port": 8080,
    "Type": "HTTP",
    "Country": "United States",
    "Speed": 100,
    "IsAvailable": true,
    "LastChecked": "2024-01-01T12:00:00",
    "Source": "https://example.com"
  }
]
```

## Требования

- .NET 6.0 или выше
- Windows 10/11
- Интернет соединение для парсинга прокси
- Минимум 100 МБ свободного места для хранения данных

## Устранение неполадок

### Проблемы с парсингом
- Проверьте интернет соединение
- Некоторые сайты могут блокировать автоматические запросы
- Попробуйте использовать VPN

### Медленная работа
- Уменьшите количество одновременных проверок в настройках
- Отключите автообновление при необходимости
- Очистите старые неработающие прокси

### Ошибки сохранения
- Проверьте права доступа к папке программы
- Убедитесь, что файлы не заблокированы другими программами

## Лицензия

Этот проект создан в образовательных целях. Используйте прокси серверы в соответствии с их условиями использования и местным законодательством.
