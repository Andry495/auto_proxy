# 🚀 Proxy Collector

[![.NET](https://img.shields.io/badge/.NET-8.0-blue.svg)](https://dotnet.microsoft.com/download)
[![Windows](https://img.shields.io/badge/Platform-Windows-green.svg)](https://www.microsoft.com/windows)
[![License](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

**Proxy Collector** - это мощная программа на C# Windows Forms для автоматического коллекционирования, проверки и управления прокси серверами с поддержкой различных протоколов и фонового режима работы.

## ✨ Основные возможности

### 🔍 Автоматический парсинг прокси
- **Поддержка популярных сайтов:**
  - [hide-my-name.com](https://hide-my-name.com/proxy-list/)
  - [proxyscrape.com](https://proxyscrape.com/free-proxy-list)
  - [freeproxylist.ru](https://freeproxylist.ru/)
  - [free-proxy-list.net](https://free-proxy-list.net/)

### 🌐 Поддержка протоколов
- **HTTP** - для веб-браузинга
- **HTTPS** - для защищенных соединений  
- **SOCKS4** - для TCP соединений
- **SOCKS5** - для TCP/UDP соединений

### ⚡ Автоматическая проверка
- **Многопоточная проверка** доступности (до 10 одновременных)
- **Измерение времени отклика** и скорости
- **Автоматическое обновление** статуса прокси
- **Интеллектуальная фильтрация** неработающих прокси

### 💾 Гибкое сохранение
- **Локальные файлы:** TXT, JSON, CSV форматы
- **Автоматическое резервное копирование**
- **Экспорт отфильтрованных данных**
- **Структурированное хранение** с метаданными

### 🎯 Продвинутый интерфейс
- **Интерактивная таблица** с сортировкой
- **Мощные фильтры:** по типу, стране, IP, доступности
- **Статистика в реальном времени**
- **Прогресс-бары** для длительных операций

### 🔄 Фоновый режим
- **Сворачивание в системный трей**
- **Автоматические проверки** каждые 5 минут
- **Непрерывная работа** в фоне
- **Уведомления** о статусе операций

## 🚀 Быстрый старт

### Предварительные требования
- **.NET 8.0** или выше
- **Windows 10/11**
- **Интернет соединение** для парсинга прокси

### Установка и запуск

#### 1. Клонирование репозитория
```bash
git clone https://github.com/Andry495/auto_proxy.git
cd auto_proxy
```

#### 2. Сборка проекта
```bash
# Через .NET CLI
dotnet build

# Или через batch файл (Windows)
build.bat
```

#### 3. Запуск приложения
```bash
# Через .NET CLI
dotnet run

# Или через batch файл (Windows)
run.bat
```

#### 4. Через Visual Studio
- Откройте `ProxyCollector.csproj` в Visual Studio
- Нажмите `F5` или `Ctrl+F5` для запуска

## 📖 Использование

### 🎯 Основные функции

| Функция | Описание | Кнопка |
|---------|----------|--------|
| **Парсинг** | Сбор прокси с сайтов | "Парсить новые" |
| **Проверка** | Тестирование доступности | "Проверить все" |
| **Обновление** | Обновление списка | "Обновить" |
| **Экспорт** | Сохранение данных | "Экспорт" |

### 🔍 Фильтрация и поиск

- **По типу:** HTTP, HTTPS, SOCKS4, SOCKS5
- **По стране:** выпадающий список всех стран
- **По IP:** поиск по части IP адреса
- **Только доступные:** фильтр рабочих прокси

### ⚙️ Настройки

- **Автообновление:** каждые 30 секунд
- **Фоновый режим:** работа в трее + проверки каждые 5 минут
- **Экспорт:** TXT, CSV, JSON форматы

### 🔄 Фоновый режим

При включении фонового режима:
- ✅ Сворачивание в системный трей
- ✅ Непрерывная работа в фоне  
- ✅ Автоматические проверки каждые 5 минут
- ✅ Уведомления о статусе операций

## 🏗️ Архитектура проекта

```
ProxyCollector/
├── 📁 Models/
│   └── ProxyServer.cs          # Модель прокси сервера
├── 📁 Services/
│   ├── ProxyParser.cs          # Парсинг с веб-сайтов
│   ├── ProxyChecker.cs         # Проверка доступности
│   └── ProxyStorage.cs         # Сохранение/загрузка данных
├── 📄 MainForm.cs              # Основной интерфейс
├── 📄 Program.cs               # Точка входа приложения
└── 📄 ProxyCollector.csproj   # Файл проекта .NET
```

### 🔧 Технические детали

- **Платформа:** .NET 8.0 Windows Forms
- **Парсинг:** HtmlAgilityPack для веб-скрапинга
- **Проверка:** HttpClient с настраиваемыми таймаутами
- **Сохранение:** JSON, TXT, CSV форматы
- **Многопоточность:** SemaphoreSlim для контроля потоков

## 📊 Форматы данных

### Текстовый формат (proxies.txt)
```
# Proxy List - Generated: 2024-01-01 12:00:00
# Format: IP:Port|Type|Country|Speed|Available|LastChecked|Source
192.168.1.1:8080|HTTP|United States|100|True|2024-01-01 12:00:00|https://example.com
```

### JSON формат (proxies.json)
```json
[
  {
    "IpAddress": "192.168.1.1",
    "Port": 8080,
    "Type": "HTTP",
    "Country": "United States",
    "Speed": 100,
    "IsAvailable": true,
    "LastChecked": "2024-01-01T12:00:00",
    "Source": "https://example.com"
  }
]
```

## 🐛 Устранение неполадок

| Проблема | Решение |
|----------|---------|
| **Парсинг не работает** | Проверьте интернет, попробуйте VPN |
| **Медленная работа** | Уменьшите количество потоков, отключите автообновление |
| **Ошибки сохранения** | Проверьте права доступа к папке |
| **Программа не запускается** | Убедитесь в наличии .NET 8.0 |
