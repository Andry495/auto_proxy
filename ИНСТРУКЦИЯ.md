# Proxy Collector - Инструкция по использованию

## 🚀 Быстрый старт

### Запуск программы
1. **Через командную строку:**
   ```bash
   cd "D:\project\C#\Proxy"
   dotnet run
   ```

2. **Через batch файл:**
   - Двойной клик на `run.bat`

3. **Через Visual Studio:**
   - Откройте `ProxyCollector.csproj`
   - Нажмите F5 или Ctrl+F5

## 📋 Основные функции

### 1. Парсинг прокси серверов
- **Кнопка "Парсить новые"** - собирает прокси с указанных сайтов
- **Автоматическая проверка** доступности найденных прокси
- **Поддержка сайтов:**
  - hide-my-name.com/proxy-list/
  - proxyscrape.com/free-proxy-list
  - freeproxylist.ru/
  - free-proxy-list.net/

### 2. Проверка доступности
- **Кнопка "Проверить все"** - проверяет все сохраненные прокси
- **Автоматическое измерение** времени отклика
- **Обновление статуса** доступности

### 3. Фильтрация и поиск
- **По типу прокси:** HTTP, HTTPS, SOCKS4, SOCKS5
- **По стране:** выпадающий список всех доступных стран
- **По IP адресу:** поиск по части IP
- **Только доступные:** показ только рабочих прокси

### 4. Экспорт данных
- **Форматы:** TXT, CSV, JSON
- **Фильтрация:** экспорт только отфильтрованных данных
- **Сохранение:** выбор места сохранения

## ⚙️ Настройки

### Автообновление
- **Включение:** Меню → Настройки → Автообновление
- **Интервал:** каждые 30 секунд
- **Функция:** автоматическое обновление списка прокси

### Фоновый режим
- **Включение:** Меню → Настройки → Фоновый режим
- **Поведение:** сворачивание в системный трей
- **Проверка:** каждые 5 минут в фоне

## 🔧 Технические детали

### Поддерживаемые типы прокси
- **HTTP** - для веб-браузинга
- **HTTPS** - для защищенных соединений
- **SOCKS4** - для TCP соединений
- **SOCKS5** - для TCP/UDP соединений

### Форматы сохранения
- **proxies.txt** - текстовый формат
- **proxies.json** - JSON с полной информацией
- **Экспорт** - пользовательские форматы

### Производительность
- **Одновременные проверки:** до 10 прокси
- **Таймаут:** 10 секунд на проверку
- **Память:** автоматическая очистка старых данных

## 🎯 Рекомендации по использованию

### Для начинающих
1. Запустите программу
2. Нажмите "Парсить новые" для получения прокси
3. Нажмите "Проверить все" для проверки доступности
4. Используйте фильтры для поиска нужных прокси
5. Экспортируйте результаты

### Для продвинутых пользователей
1. Включите автообновление для постоянного мониторинга
2. Используйте фоновый режим для работы в трее
3. Настройте периодические проверки
4. Экспортируйте данные в нужном формате

## 🚨 Устранение неполадок

### Программа не запускается
- Убедитесь, что установлен .NET 8.0
- Проверьте права доступа к папке
- Запустите от имени администратора

### Медленная работа
- Уменьшите количество одновременных проверок
- Отключите автообновление
- Очистите старые неработающие прокси

### Ошибки парсинга
- Проверьте интернет соединение
- Некоторые сайты могут блокировать автоматические запросы
- Попробуйте использовать VPN

### Проблемы с сохранением
- Проверьте права доступа к папке
- Убедитесь, что файлы не заблокированы
- Проверьте свободное место на диске

## 📊 Статистика

Программа отображает:
- **Общее количество** прокси в базе
- **Количество доступных** прокси
- **Время последней проверки**
- **Скорость работы** прокси

## 🔒 Безопасность

- Программа не сохраняет личные данные
- Все прокси получаются из публичных источников
- Используйте прокси в соответствии с их условиями
- Соблюдайте местное законодательство

При возникновении проблем:

2. Убедитесь в корректности настроек
3. Перезапустите программу
4. Проверьте доступность исходных сайтов
